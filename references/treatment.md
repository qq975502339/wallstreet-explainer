# 画法：每期按选题定制（v1.4 接入）

版式只是**骨架**（坐标轴/箭头/扇区/航线/排布/入场节奏），管"数据怎么排"；**画法**管"这期长什么样"：骨架上压本期话题的真实照片 + 放本期生成的小道具，道具承担意思。只换数据不换画法 = 每期像同一套 PPT。

## 画法设计表（写镜头表前先写）

| 场景 | 覆盖哪几句 | 骨架 | 背景（本期真实画面） | 道具和动作（本期隐喻） | 事实编号 | 硬切/弱口型是否盖住 |
|---|---|---|---|---|---|---|
| 例：价格十年 | chart | 咖啡豆特写照片（under） | 咖啡豆小人骑线头往上爬（rider） |
| 例：一杯的成本 | share | 咖啡馆吧台照片（under） | 拿铁俯视图切 4 块（img），讲到豆子那块推出 |
| 例：产地运输 | map | 港口照片（under） | 货轮沿航线开（vehicle），产地放麻袋（prop 节点） |
| 例：利润拆解 | tree | 咖啡师照片（under） | 节点配道具：钱袋/收银机/外带杯（type:'prop'） |
| 例：品牌关系 | network | 咖啡馆照片（under） | 供豆边跑麻袋、管理费边跑金币（dot） |

换选题骨架可复用，**画法必须重做**。

## 三条检查（--check 会提醒第一条）

1. **每个图形场景至少一样本期专属物**：under 照片 / rider / img / props / 真 img/photo/logo / vehicle / dot，至少一样。只有骨架+数字 = 不合格。
2. **道具承担意思**：拿掉它意思变弱才算对（骑线头=价格在爬；切拿铁=一杯钱去向；变红的包=有漏洞）。纯装饰不算。
3. **相邻场景动作不重样**：骑/切/开/流/堆 不要连着用同一种。

**遮罩自检**：遮住道具和背景只看骨架，若和别的选题没区别 = 画法没做。

## 与句型表配合（先句型后画法，不要反过来）

| 句型 | 骨架仍按 shot-grammar | 画法上多做的事 |
|---|---|---|
| N1 单数字 | number + host 让位 | 对侧/底图用本期实拍，不要空底配孤零零数字 |
| N2 序列 | chart/bars/ranking | 底图本期场景；柱/线出现=该句开头；写法跟口播 |
| C 对比 | compare/versus | 两侧各放代表双方的真画面/Logo |
| K/L 因果/清单 | chain/连续 statement | 每步一个看得懂的实物或截图，不只堆文字 |
| T 术语 | statement/board 卡 | 配该事物真照片/Logo；外文小字不含数字 |
| S 故事 | footage/montage 或 story 段 | 中英关键词搜可商用实拍；不用图片社照片/别人视频截帧 |

开场钩子/设问/结论仍优先全屏人物，不要全盖讲解画面。道具优先可商用实拍/Commons/官方截图/真 Logo；专用透明 PNG 须标来源或"AI 生成"；**不生成品牌 Logo、真人肖像、"好像现场证据"的假照片**；一期道具同一画风。

## 背景照片规矩

`under:{img, br:.5, blur:3}`：压暗 0.5–0.7、虚化 2–6px、慢推 1.06→1.11；照片是**背景不是主体**，主体仍是骨架+道具；照片来源走 sourcing（Commons CC / 授权实拍），署名进 CREDITS/简介（规矩 16 不上屏）。

## 道具从哪来

`references/prop-styles.md`：20 画风选一种 → gen_image（suffix+tail+小样参考）→ prop_prep → `K.prop`/插槽/prop 节点。道具标 AI生成（规矩 40）、进账本 P 条。

## 挂载点速查

- 通用：任何镜 `props:[{img,x,y,w,at,look,idle,path,copies,tint,…}]`（独立 overlay 相机，`cam` 可给键帧）；
- 插槽：`chart.rider` / `share.img` / `map|network|flow.links[].vehicle|dot` / board `nodes[].type:'prop'`；
- 手写档：`K.prop(o,t,st)` 直接进 L 层（跟宿主同层保证运动模糊一致）。
