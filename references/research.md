# 事实查核与账本

上屏的数字、原文、照片都要**先查到、写进账本**（模板 `references/facts_template.md`），再写分镜。查不到的东西不上屏。

**出处和署名的去向：CREDITS.md 和视频简介（规矩 16）。本项目不在画面上加任何来源小字，版式没有 `src` 参数，也不借源项目"来源上屏"的做法。** 账本管的是"够不够格上屏、错了能不能复核"，不是"印在哪"。

## 什么时候查

1. 站 0 选题定下后建账本：`<片子>/facts.md`，从模板复制。
2. 站 2 导演表加一列"需要的资料"：每镜的数字/原文/照片写账本编号（F/D/P）。
3. 站 4 写分镜前按这一列逐条查，结果进账本；**台词里说到的数字也必须在账本里**，台词和画面共用同一条记录。
4. 回改导演表：查不到就换场景（见下"回改"），不要硬凑。

## 来源分级

| 级别 | 例子 | 能否上屏 |
|---|---|---|
| 一手 | 统计公报和年鉴、政府文件原文、法律条文、央行和监管机构报告、公司财报和公告、国际组织数据库 | 能 |
| 权威转述 | 新华社、人民网、Reuters、Bloomberg、FT 引用的一手数据 | 能，账本标"权威转述"；能找到一手时换一手 |
| 推算 | 用一手数据自己算的值（人均、比值、每天、复利） | 能，上屏写"约"或"推算"，**算式写进账本** |
| 线索 | 自媒体、百科、论坛、AI 回答 | **不能**。只用来找一手来源；找不到就进"未验证"区，不上屏 |

## 每种场景要查什么

| 场景 | 要查到的资料 | 最低要求 |
|---|---|---|
| `number` `stats` `bars` `ranking` `compare` | 每个数：值、单位、口径、年份 | 一手或权威转述；同源同口径同单位才能排在一起比 |
| `equation` `calc` | 计算规则 + 每个输入值 | 规则来自正式文件/财报口径；算例自己算，算式进账本 |
| `change` | from 和 to 两个数 | 同口径同来源；倍数是推算，标"约" |
| `chart` `line` | 序列（或日线）+ 出处 | 同一来源、同一口径、同一单位；`line` 要真实日线（如 Yahoo Finance 收盘），出处进账本和 brief；凑不齐就换 `number`/`bars` |
| `share` `grid` | 各部分值 / 总数 n 与命中数 hi | 口径一致、hi ≤ n；`grid` 的总数要"数得清"（报告样本量、公开清单），数不清就用 `share` 的有源百分比 |
| `tree` | 拆解规则 + 每个叶子值 | 规则来自财报/正式文件；叶子同口径 |
| `versus` | 两个按面积比的值 | 同口径；面积比是真的，别拿不同口径凑反差 |
| `discs` `network` `flow` `board` `map` | 每个实体中英文名 + 1 个标签事实；边上的持股%/金额 | 实体事实可核；持股/合同额来自公告或财报；`map` 国家数据同口径，`countries` 用 ISO 三字码 |
| `timeline` | 每个事件的年份 + 一句事实 | 日期可核（先后顺序别错） |
| `person` `profile` | 身份、事实（≤3 条） | **按片子发布那天核**（职位会变）；每条事实有出处 |
| `quote` | 逐字原话 + 出处（谁·哪一场） | 翻译不改意思；`hl` 的字原样在原话里；英文原文可上 `orig` 一行 |
| `article` | 截图 url + 拍摄日期 + 高亮句逐字 | 高亮句与原文逐字一致；截不到用 `mock`（核实过的文字、通用样式、不仿真站） |
| `docpage` | 逐字原文 2–6 句 + 文件名/条款 + 发布日期 | **逐字，不改写不拼接**；外文原文直接上外文、中文放字幕；找不到逐字原文就不用 `docpage` |
| `desk` `headlines` `flash` | 每条来自核实过的报道 | 标题/摘要不编；`flash` 至少 8 条真出处或开放式问题 |
| `footage` `montage` `frames` `popup` `device` | 素材出处 + 引用理由 | 出处进 CREDITS；`device` 界面截图记版本/日期 |
| `stack` | n 与"一张=什么"的定义 + 总值 | 定义自洽、总值有源 |
| `bubble` | 误区确实普遍存在的证据 | 概括说法 + 虚构昵称；不搬真实用户原话 |
| `title` `agenda` `statement` | 不需要新数据 | `statement` 的判断必须能被前面账本条目支撑 |
| `custom` | 上屏的一切 | 同上述对应类型 |

## 去哪里查

- 中国：国家统计局公报/年鉴、部委公报、中国政府网政策库、国家法律法规数据库、央行/证监会、交易所公告。部委站打不开时搜文件全名，地方政府转载页要核对文号和发布日期。
- 海外：各国统计局、SEC EDGAR、World Bank/IMF/OECD、公司财报与公告。
- 先搜索再**打开原页面或 PDF 读原文**，不要只看搜索摘要。环境里有 `data-api`/`deep-research` 类 skill 时优先用。
- 照片/Logo/图库空镜/生成图/新闻截图：走 `references/sourcing.md` 的脚本与许可规矩（commons_photo/commons_logo/stock/gen_image/snap_news），侧车和 CREDITS 照旧。

## 规则

1. 上屏数字 = 账本数字；万/亿/百分点的换算写进账本。
2. 用最新已发布年份；还没发布的数据不说。
3. 每条记两个日期：来源发布日期 + 查阅日期。
4. 不同来源冲突：用一手，账本写明差异。
5. 演示/示意数据：上屏标"示意"（kit 已有），账本里也标，不混进真数。
6. 推算值上屏标"约/推算"，算式和输入编号进账本。
7. **来源不上屏**：不加来源小字、不加 `src`；出处和署名进 CREDITS.md/简介（规矩 16）。画面上的来源字只能是原文截图自己带的。

## 口播原样与定稿保护（B 层补）

1. **屏幕写法 = 口播写法**：万/亿/%/单位跟口播同一个样子（"1万"就写"1万"，不换算成 10,000）；换算关系写进账本，不上屏。参考片做换算（证据 E12），**不学**。
2. **台词与画面不一致时，先改画面或改素材，不要擅自改已定稿的口播**；定稿口播要改必须先问用户。
3. 口径三问：地方数据用**当地官方口径**（不拿全国/外地冒充当地）；对比只在**同一时间窗口、同一口径**里做；先看有没有**更新年份**，没公布的不说也不"预估"。
4. 数字出现时刻 = 包含它那句的开头（+0.1s），不等念完（证据 E12）；路过的数字只留字幕（E3）。

## 回改（查不到就换场景）

- 找不到逐字原文 → 不用 `docpage`；改 `article` mock（核实文字）或 `quote`。
- 凑不齐同口径序列 → 不用 `chart`/`line`；改 `number`/`bars`/`stats`。
- 总数数不清 → 不用 `grid`；改 `share`（有源百分比）或 `number`。
- 身份/事实核不到 → 不进 `profile` 的 facts；只留名字和已核身份。
- 误区没有普遍性证据 → 不用 `bubble`；口播直接说或删。
