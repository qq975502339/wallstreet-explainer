# 分镜语法：句型→镜头 + 节奏尺子 + 机位（B 层借鉴）

> 思路借鉴 zenskill-xiaolinshuo-video 的 STYLE_RULES（其规则来自对公开参考片的拆解，时间码证据见 `reference-evidence.md`）；**本文按本项目口径重写**：30fps、-14 LUFS、AI 必标（规矩 40/44）、来源不上屏（规矩 16）、kit 42 场景 + host `zoom` 机位。规则是**提醒不是配额**：内容需要停顿/长镜时以叙事为准，答得上理由就留。

## 0 三道闸优先（压过下面所有句型）

| 闸 | 规则 | 现在谁拦 |
|---|---|---|
| G1 穿帮覆盖 | 硬切断点（±2 帧）与弱口型句**必须落在全屏 B-roll/卡/章节上**，不能是人物镜 | 导演表标 + review 人查（机器门禁在未接的 A3 备选里） |
| G2 数字原样 | 屏幕写法 = 口播写法（"1万"就写"1万"，**不换算**成 10,000） | facts_check 对账本；口播一致人查 |
| G3 许可 | 只用可商用来源，禁 ND/NC；署名进 CREDITS/简介 | sourcing 规矩 + 侧车 |

被 G1 要求盖住时：N1/N2/C/K 改用全屏卡版本；S/H/N0 用 B-roll；T/L 用卡。

## 1 句型→镜头（先中先用，一句一类）

| 代号 | 句型判定 | 本项目镜头 |
|---|---|---|
| H | 片头前 1–3 句 + 紧跟的反差串烧段 | host `zoom x:0` 全景 → 主题词那句句首 `zoom s:1.2` 台阶推近 → `title` 卡 2.5–3.5s **压住下一句开头** → `footage/montage` 串烧每镜 0.6–1.4s，**只首镜** `host:'pip'` |
| T | "叫做/号称/被称作/史称"+引号词 | 术语出口 0–3s 内切 `statement`/board 术语卡（大字+外文小字，**小字不含数字**），停 1.5–3s 回人物 |
| N1 | 这句就是在讲这一个数（短句或"涨到/跌到/翻倍/%/相当于"） | host `zoom x:±.3` 让位 + 对侧 `number`；text=口播原样；**at=这句开头+0.1s**（不等数字念完） |
| N2 | 20s 内≥2 个"年份/阶段+数字"，或走势/排名/换算 | `chart/bars/ranking` 全屏卡；每根柱 at=该句开头；主角柱单独 color；镜头≥4s 加 `host:'pip'`；走势"边说边画"用 `chart draw{at,until}` 或拆两镜 |
| N0 | 有数字但重点不在数字（串烧/故事顺嘴带过） | **不做图表**，只靠字幕 |
| C | "A…而/但 B""官方…黑市""不是…而是""相比" | `compare/versus`；两侧配代表双方的真画面/Logo，不只写两个词 |
| K | 25s 内≥3 步"因为/就会/导致/所以" | ≤3 步：host 让位+board 链（词→箭头→词→结果，逐个 at）；>3 步：`chain` 全屏+pip |
| L | 连续≥3 个并列短语 | 连续 `statement` 关键词卡每镜 1.2–1.6s（修饰语小字+关键词大字），负面用 brick |
| S | 具体场景/人物/地点，"你看/比如/当时/有一次" | `footage/montage` 段 4–16s、每镜 0.8–2.1s；**人物经历/创业/公司历史**走 story 段（bighead，见 story-mode.md） |
| Q | "为什么呢/你说/怎么办/这谁受得了" | host `zoom s:1.2` 近景，**不放面板** |
| E | "所以说/其实/说白了/总之" | host 全景，最多一个关键词 |
| CH | "第X章/条" | 参考片**没有数字章节卡**（E9）：用 `flash/agenda` 关键词目录卡造章节感 |

## 1B 内容类型→场景（句型表之外的触发，补全 42 场景）

句型表管"口播句怎么拍"；下面这张管"**这句话的内容类型**该用哪个场景"——证据类/关系类/包装类不由数字句型触发。两张表合起来覆盖全部 42 场景（机器核过，见 borrow-ledger）。

| 触发（内容类型） | 场景 | 要点 |
|---|---|---|
| "从 X 变到 Y / 翻倍 / 腰斩" | `change` | from/to 同口径同来源；倍数是推算标"约" |
| "几个数并列摆一起" | `stats` | 同源同口径同单位才能排一起 |
| "谁第一 / 前 N / 排名" | `ranking` | 主角那条单独色；其余压暗 |
| "算一笔账 / 公式 / 复利" | `equation` | 规则来自正式文件/财报口径；算式进账本 |
| "几家并列、各一个数" | `discs` | 每实体中英文名+1 标签事实 |
| "谁投谁 / 持股 / 资金流" | `network` | 边% /金额来自公告财报；dot 道具流 |
| "步骤 / 产业链 / 转一圈" | `flow` | 回环用 loop；每步一个看得懂的实物 |
| "沿革 / 年份节点 / 先后" | `timeline` | 日期可核、顺序别错；below 变体放说明 |
| "产地 / 路线 / 分布 / 国家对比" | `map` | countries 用 ISO 三字码；vehicle 沿航线；涉中国疆域用审图号地图 |
| "一群里拎出一个" | `cards3d` | 跟拍+其余虚化 |
| "自由摆 / 两侧浮卡 / 词链" | `board` | 节点左右摆=参考片两侧浮卡（E14） |
| "人物站在巨字前 / 出场" | `person` | 身份按发布日核 |
| "人物介绍（≤3 条事实）" | `profile` | 每条事实有出处 |
| "真人原话 / 引语" | `quote` | 逐字+出处（谁·哪一场）；hl 字原样在原话里 |
| "全屏实拍一段" | `footage` | 出处进 CREDITS；单次使用禁循环 |
| "钉住画面换实拍" | `montage` | 同上；成段 4–16s |
| "几个画框并列对比" | `frames` | 每框出处+引用理由 |
| "报道/公报原文高亮" | `article` | 真截图+hl 逐字；截不到用 mock |
| "逐字原文页（法规/条款）" | `docpage` | 逐字不改写不拼接；找不到不用 |
| "新闻桌面圈注/盖章" | `desk` | 每张截图各自带 hl/scribble/stamp |
| "反应窗 / 吐槽插话" | `popup` | 核实过的报道；1–2s |
| "标题墙 / 多家报道" | `headlines` | 每条真出处 |
| "产品界面 / 操作演示" | `device` | 截图记版本/日期 |
| "一项拆成几项" | `tree` | 拆解规则来自财报/正式文件 |
| "如果你…会怎样（测算）" | `calc` | 输入值有源；上屏与口播一致 |
| "钞票堆 / 一张=什么" | `stack` | n 与定义自洽、总值有源 |
| "每 100 个里有多少" | `grid` | 总数要数得清；数不清改 share |
| "误区 / 普遍说法" | `bubble` | 普遍性证据+虚构昵称 |
| "真实日线走势" | `line` | 真实收盘序列+出处；凑不齐改 number/bars |
| "因果链（≥3 步）" | `chain` | 逐个 at；>3 步加 pip |
| "片名 / 目录 / 快闪 / 金句" | `title` `agenda` `flash` `statement` | 结构触发；statement 判断须被账本支撑 |
| "主持人出镜（全/挂墙/换世界/圆窗/竖窗）" | `host` | 机位见 §3；穿帮点不能是人物镜（G1） |
| "以上都不贴合" | `custom` | 手写镜兜底；上屏的一切仍进账本 |

**优先级**：G1 覆盖 > 手势 > 句型表（§1）> 本表；证据类场景永远真素材，道具不进去冒充证据。

## 2 节奏尺子（提醒值，参考片实测见证据库 E5）

| 指标 | 提醒值 |
|---|---|
| 切点密度 | 25–35 次/分钟 |
| 人物镜 | 2.5–6s（超 6s 考虑拆） |
| B-roll 单镜 | 0.8–2.1s（开场串烧 0.6–1.4s） |
| B-roll 段 | 4–16s 成段，段间回人物；**不要人物/实拍一镜一换** |
| 人物占比 | 30–45% |
| pip 小窗 | ≤镜头数 10%；优先串烧首镜与≥4s 全屏图表卡 |
| 字幕 | 单行底部居中，≤14 字参考（语义处断） |

## 3 机位语法（host `zoom:[{at,s,x}]`）

- **居中优先**：没面板时 `x:0`（参考片人脸 95% 落在横向 49–52%，E4）；**只有给图表让位才 `x:±`**。
- **台阶推近**：`s≈1.2`（1.14–1.2 实测）跳在**新句开头**，host zoom 本就是硬跳，不是慢推；同一镜再推一档=再加一个 zoom key。
- **手势镜头慢推**（推镜起点=手势起点、dur≈0.6）：host zoom 是硬跳**做不了慢推**→ 用 footage `push` 或 custom 手写，或记备注；不硬凑。
- 全景/近景倍率关系：close ≈ wide×1.2。

## 4 手势表（可选，B3）

`gestures.tsv`：句 | 句起(s) | 句止(s) | 计划手势 | 重音词 | 重音时刻(s) | 手部入画区间(s)。
用法：推镜/切镜 key 的 `at` 放**手势起点**（绝对秒），让观众感觉"他一挥手镜头就凑近"。无手势写"无"。数字人没手势就不用这张表。

## 5 画面参数

- 数字/元素出现时刻 = 包含它那句的开头（+0.1s）；长图表镜**每 3–5s 要有新元素**（新柱/新行/新词），否则拆镜。
- **当前项最亮、讲过的压暗**（kit focus/dim 已有）；排名主角柱单独色。
- 颜色语义：当前/高亮=gold，中性标签=teal，负面/下跌=brick（不用粉紫）。
- 双语小字只跟标题/术语/流程框，**不含数字**。
- 转场默认硬切；动画转场只放进出实拍段/章节切换，不要每个切点都甩镜。
- 主体要大：图表/大数字/关键词宽度尽量≥画面六成或被边缘裁切，不要小块居中四周空。

## 6 做得到 / 做不到（对照参考片手法）

| 参考片手法 | 本项目 |
|---|---|
| 人物两侧各浮一张卡 | ✅ board 节点左右摆 |
| 圆角矩形竖条小窗 | ✅ host 竖窗排布 |
| 卡片墙跟拍、其余虚化 | ✅ cards3d |
| 原文页荧光笔/网页聚光 | ✅ docpage / article hl |
| 饼图切真实照片 / 道具骑线头 | ✅ share img / chart rider |
| 地图航线 / 关系资金流 / 象形堆 / 计算器 | ✅ map / network / stack·grid / calc |
| 一镜内多次台阶推近 | ✅ zoom 多 key |
| 片名卡溶解转场 | ❌ 无 dissolve → cut/whip |
| 换算型数字（1万→10,000） | ❌ 违反 G2，永远不做 |
| 手势慢推 | ❌ host 硬跳 → footage push/custom/备注 |
